# VAT7 ครู – เว็บแอพคำนวณภาษีมูลค่าเพิ่ม 7%

เว็บแอพแบบ PWA/SPA สำหรับครูและงานพัสดุโรงเรียน ใช้คำนวณ VAT 7% ได้บนมือถือและคอมพิวเตอร์
ติดตั้งลงหน้าจอโฮมได้ และใช้งานได้แม้ไม่มีอินเทอร์เน็ต ไม่ต้องติดตั้งอะไรเพิ่ม (HTML/CSS/JS ล้วน ไม่มีขั้นตอน build)

## ความสามารถ

- **คำนวณเร็ว** – กรอกยอดเดียว เลือกได้ว่ายอดนั้น *รวม VAT แล้ว* (ถอด VAT) หรือ *ยังไม่รวม VAT* (บวก VAT)
- **ฎีกา/รายการ** – กรอกข้อมูลฎีกา ผู้ขาย และรายการสินค้า (ชื่อ, จำนวน, ราคา/หน่วย) แล้วสรุปยอดตามแบบฎีกาเบิกจ่าย:
  จำนวนเงินที่เบิก → ภาษีมูลค่าเพิ่ม → ค่าสินค้าหรือบริการ → ภาษีเงินได้หัก ณ ที่จ่าย → ค่าปรับ → จำนวนเงินขอรับ
- **พิมพ์เอกสาร** – ตารางรายการ, งบหน้าประกอบฎีกา, ใบสั่งจ่าย, แบบแนบฎีกาแสดงรายการภาษี (แนวนอน), ใบรับรองการหักภาษี ณ ที่จ่าย (บก.28)
- **Export Excel** – สร้างไฟล์ .xlsx 6 ชีต (ฎีกา, รายการ, งบหน้า, ใบสั่งจ่าย, แนบฎีกา, รับรองภาษี) พร้อมสูตรคำนวณจริงในเซลล์ แก้ตัวเลขใน Excel แล้วคำนวณใหม่เองได้ ไม่ใช้ library ภายนอก ทำงานออฟไลน์ได้
- **หัก ณ ที่จ่าย** – 1% (ส่วนราชการจ่าย), 2%, 3%, 5% แยกกฎตามประเภทผู้รับเงิน: นิติบุคคลหักทุกจำนวน (ม.69 ทวิ), บุคคลธรรมดาหักเมื่อตั้งแต่ 10,000 บาท (ม.50(4))
- **หักค่าปรับ** – กรอกค่าปรับ (ถ้ามี) ระบบหักออกจากยอดขอรับให้
- **อ่านจำนวนเงินเป็นตัวอักษร** เช่น "หนึ่งพันเจ็ดสิบบาทถ้วน" สำหรับกรอกเอกสาร
- **คัดลอก / แชร์** ผลลัพธ์เป็นข้อความ ส่งต่อทางไลน์หรือแชตได้ทันที
- **ประวัติ** – บันทึกการคำนวณไว้ในเครื่อง เปิดกลับมาแก้ไขได้
- **ตั้งค่า** – อัตรา VAT, หัก ณ ที่จ่ายเริ่มต้น, ข้อมูลส่วนราชการสำหรับพิมพ์เอกสาร, ธีมสว่าง/มืด
- รองรับการพิมพ์เลขไทย (๐-๙) ในช่องตัวเลข

## วิธีคิด

| กรณี | สูตร |
|---|---|
| ถอด VAT (ยอดรวม VAT แล้ว) | ค่าสินค้าหรือบริการ = จำนวนเงินที่เบิก × 100 ÷ 107, VAT = จำนวนเงินที่เบิก − ค่าสินค้า |
| บวก VAT (ยอดยังไม่รวม VAT) | VAT = ค่าสินค้า × 7 ÷ 100, จำนวนเงินที่เบิก = ค่าสินค้า + VAT |
| หัก ณ ที่จ่าย | คิดจากค่าสินค้าหรือบริการ (ก่อน VAT) |
| จำนวนเงินขอรับ | จำนวนเงินที่เบิก − ภาษีหัก ณ ที่จ่าย − ค่าปรับ |

ตัวอย่างจากแบบแนบฎีกา: เบิก 5,000.00 → VAT 327.10, ค่าสินค้า 4,672.90, หัก 1% = 46.73, ขอรับ 4,953.27

ปัดเศษทศนิยม 2 ตำแหน่ง (สตางค์)

## รันในเครื่อง

PWA ต้องเปิดผ่าน `http://localhost` หรือ `https://` เท่านั้น (เปิดไฟล์ตรง ๆ จะใช้ service worker ไม่ได้)

```bash
python -m http.server 8085
```

แล้วเปิด <http://localhost:8085>

## นำขึ้นใช้งานจริง

โฟลเดอร์นี้เป็น static site อัปโหลดทั้งโฟลเดอร์ขึ้นที่ใดก็ได้ที่ให้บริการ HTTPS เช่น

- **GitHub Pages** – push ขึ้น repo แล้วเปิด Pages จากโฟลเดอร์ราก
- **Netlify / Vercel / Cloudflare Pages** – ลากโฟลเดอร์ไปวาง ไม่ต้องตั้งค่า build
- โฮสต์โรงเรียนที่มี HTTPS – คัดลอกไฟล์ทั้งหมดขึ้นไป

ทุกไฟล์ใช้ path แบบ relative จึงวางไว้ใต้โฟลเดอร์ย่อยได้ (เช่น `https://school.ac.th/vat7/`)

## ติดตั้งเป็นแอพ

- **Android / Chrome / Edge** – กด "ติดตั้ง" ในแอพ หรือเมนูเบราว์เซอร์ → เพิ่มลงหน้าจอหลัก
- **iPhone / iPad** – เปิดด้วย Safari → ปุ่มแชร์ → เพิ่มลงในหน้าจอโฮม

## อัปเดตเวอร์ชัน

เมื่อแก้ไขไฟล์ ให้เปลี่ยนค่า `CACHE` ใน `sw.js` (เช่น `vat7-v1.0.1`) และ `APP_VERSION` ใน `app.js`
ผู้ใช้จะเห็นแถบ "มีเวอร์ชันใหม่" และกดอัปเดตได้

## โครงสร้างไฟล์

```
index.html            หน้าเดียว (SPA) มี 4 หน้าย่อย: คำนวณเร็ว, รายการสินค้า, ประวัติ, ตั้งค่า
styles.css            สไตล์ responsive + dark mode + print
app.js                ตรรกะคำนวณ, routing, localStorage, PWA install, แบบพิมพ์, สร้างสมุดงาน Excel
xlsx-writer.js        ตัวสร้างไฟล์ .xlsx ขนาดเล็ก (zip + OOXML) ไม่พึ่ง library
sw.js                 service worker (ออฟไลน์)
manifest.webmanifest  ข้อมูลแอพสำหรับติดตั้ง
icons/                ไอคอน SVG/PNG
```

ข้อมูลทั้งหมดเก็บใน localStorage ของเครื่องผู้ใช้ ไม่มีการส่งไปเซิร์ฟเวอร์ใด ๆ
